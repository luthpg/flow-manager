# 要件提示書 (Requirements Document)

## 1. プロジェクト概要
Google Apps Script (GAS) をバックエンド、Google Spreadsheet をデータベースとして利用する、サーバーレスな業務フローチャート作成・管理システム。
直感的な作図機能に加え、エンタープライズ利用に耐えうる「バージョン管理」「承認ワークフロー」「変更差分検知」を標準搭載し、業務プロセスの可視化とガバナンス強化を実現する。

## 2. 業務フロー・ユースケース

### 2.1 ユーザーロール
| ロール | 権限概要 | 想定ユーザー |
| :--- | :--- | :--- |
| **VIEWER** | 閲覧のみ | 一般社員、参照部門 |
| **EDITOR** | 作成、編集、申請 | 業務担当者、フロー設計者 |
| **APPROVER** | 閲覧、承認、否認 | マネージャー、品質管理部門 |
| **ADMIN** | 全権限、フォルダ管理 | システム管理者 |

### 2.2 主要ユースケース
1.  **フロー作成・編集**: ユーザーはブラウザ上でBPMNライクな図を作図し、下書き(Draft)として保存する。
2.  **マルチシート管理**: 1つのフロー定義内で、メインプロセスとサブプロセスを複数のシート（タブ）に分けて管理する。
3.  **承認申請**: 完成した下書きを「申請(Pending)」ステータスにし、承認者へレビューを依頼する。
4.  **差分確認 (Diff)**: 承認者は、現在公開中のバージョンと申請されたバージョンの「差分（追加・削除・変更）」を色分け表示で確認する。
5.  **承認・公開**: 承認者は差分を確認し、問題なければ承認(Approve)する。承認されたバージョンは「公開(Published)」となり、版数(Version ID)が採番される。
6.  **閲覧**: 一般ユーザーは常に最新の「公開済み」バージョンを閲覧する。

## 3. 機能要件

### 3.1 ダッシュボード (Dashboard)
* **一覧表示**: 権限のあるフローをカード形式で一覧表示する。
* **フォルダ管理**: フローをフォルダ単位で階層管理・表示する。
* **検索・フィルタ**: フロー名検索、ステータス（公開/下書き/申請中）によるフィルタリング。
* **バージョン選択**: カード上で、そのフローの過去バージョンや最新ドラフトを選択してプレビューへ遷移可能とする。

### 3.2 エディタ (Editor)
* **作図機能 (React Flow)**:
    * BPMN準拠のノード（開始/終了、タスク、分岐、スイムレーン等）をドラッグ＆ドロップで配置。
    * ノード間の接続（直線、直角折れ線）。
    * グリッドスナップ、自動整列、BPMNバリデーション機能。
* **プロパティ設定**: ノードごとの詳細情報（ラベル、担当者、説明、リンクID等）の編集。
* **マルチシート**: シートの追加、削除、リネーム、並べ替え。
* **履歴管理**: 操作ごとのUndo/Redo機能。
* **一時保存**: サーバーへの下書き保存（バージョンIDはドラフト形式で発行）。

### 3.3 プレビュー・承認画面 (Viewer)
* **閲覧モード**: 編集不可の状態でフローを表示。ズーム、パン操作は可能。
* **Diff View**: 申請中のバージョンと、現行の公開バージョンを比較し、差分を視覚的に表示（青：追加、赤：削除、緑：変更）。
* **Cherry-pick承認**: 承認者は検出された差分に対し、個別に「適用」か「却下」を選択可能とする（今回は要件として含むが、実装は全適用を基本とする）。
* **承認アクション**: コメント付きでの「承認」または「否認」。
* **履歴表示**: 過去の申請・承認コメントのタイムライン表示。

## 4. 非機能要件
* **レスポンシブ**: PCでの編集を主とするが、閲覧・承認はモバイル端末でも可能とすること（モバイル用レイアウトの適用）。
* **パフォーマンス**: 初期ロードの高速化（Viteによるバンドル最適化）。GAS特有の遅延を考慮し、ローディング表示や楽観的UI更新を適切に行う。
* **セキュリティ**:
    * GASの `Session.getActiveUser().getEmail()` を用いたユーザー認証。
    * スプレッドシート上の権限テーブルに基づくRBAC（ロールベースアクセス制御）。
* **保守性**: フロントエンドとバックエンドの型定義を共有・同期し、型安全性を担保すること。
