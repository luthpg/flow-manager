# 残タスク一覧

現在の実装状況と設計書（`design.md`, `requirement.md`）との差異に基づき、今後対応が必要なタスクを整理します。

## 1. フロントエンド (Frontend)

### 1.1 権限管理の統合
- **現状**: `src/pages/flow/[id]/[version]/preview.tsx` などで `userRole` が `'EDITOR'` にハードコードされています。
- **タスク**:
  - バックエンド(`AuthService`)から現在のユーザーの権限を取得するAPI (`getUserRole` 等) を実装し、フロントエンドで利用するように修正する。
  - `server/service/AuthService.ts` は実装済みですが、これをクライアント(`src/lib/server.ts`)から呼び出す導線が必要です。

### 1.2 Diff (差分) 機能の強化
- **現状**:
  - `src/pages/flow/[id]/[version]/preview.tsx` にて、比較対象バージョンが簡易的に処理されています (`meta.activeVersionId` を使用するTODOコメントあり)。
  - マルチシート構成の場合、現在はメインシート（またはアクティブシート）のみがDiffの対象となっている可能性があります。
- **タスク**:
  - **比較対象の正当化**: ステータスが `PENDING` の場合、明確に「申請元のドラフト」と「現在の公開版 (`activeVersionId`)」を比較するようにロジックを確定させる。
  - **マルチシート対応**: 複数のシートを持つフローの場合、全シートの差分を計算・表示できるように `resolveDiff` および `computeDiff` 周りを拡張する、またはUI上でシートごとにDiffを切り替える仕様を明確化する。

### 1.3 `use-flow-sheets.ts` の扱い
- **現状**: `design.md` に記載のあった `src/hooks/use-flow-sheets.ts` は存在しませんが、`src/stores/flow-store.ts` がシート管理機能（追加・削除・切り替え）を実装しています。
- **タスク**: 設計書の記述を修正するか、ストアの実装で十分であることの確認（完了扱いとする）。本タスクリストとしては「ストアへの統合済み」としてクローズ扱いで可。

## 2. バックエンド (Server / GAS)

### 2.1 承認・リリースフローの堅牢化
- **現状**: `FlowService.approveFlow` は実装されていますが、グラフデータ (`graphData`) の部分更新（チェリーピック）が正しく永続化されるか、結合テストが必要です。
- **タスク**:
  - 承認時に渡された `graphData` が、新しいバージョン (`YYYYMMDD`) として正しく保存されるか検証する。
  - 特にマルチシート構造のデータ整合性が保たれるか確認する。

### 2.2 エラーハンドリングとログ
- **現状**: 基本的な `try-catch` はありますが、ユーザーへのフィードバック詳細や、GAS側でのログ出力が最小限です。
- **タスク**: 本番運用を見据え、重要な操作（承認、保存、削除）のログ出力（`console.log` / Stackdriver Logging）を強化する。

## 3. テスト (Testing)

- **現状**: `tests/lib/bpmn-logic.test.ts` 等が存在しますが、UIコンポーネントや複雑なインタラクション（Diff表示、シート切り替え）のテストが不足している可能性があります。
- **タスク**:
  - `src/lib/diff-utils.ts` のエッジケース（ノード移動のみ、プロパティ変更のみ等）のユニットテスト拡充。
  - `AuthService` の権限チェックロジックのユニットテスト。

## 4. ドキュメント (Documentation)

- **タスク**:
  - `design.md` の更新: `use-flow-sheets.ts` 廃止とストア利用への変更を反映。
  - API仕様の明確化: フロントエンドとバックエンドの型定義 (`types/`) の同期確認。
