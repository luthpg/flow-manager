# 残タスク一覧

現在の実装状況と設計書（`design.md`, `requirement.md`）との差異に基づき、今後対応が必要なタスクを整理します。

## 1. フロントエンド (Frontend)

### 1.1 権限管理の「実」連携 (Priority: High)

- **現状**:
  - `src/pages/flow/[id]/[version]/preview.tsx` および `edit.tsx` にて、ユーザー権限が `const [userRole, setUserRole] = useState<Role>('EDITOR');` のようにハードコードまたは仮置きされている。
  - サーバーサイドの `getFlowData` は正しい `userRole` を返却する準備ができている。
- **タスク**:
  - `serverScripts.getFlowData` のレスポンスから `userRole` を正しく State にセットする。
  - `userRole` に基づき、以下のUI要素の表示/非表示を制御する実装を完了させる。
    - **Preview画面**: 「編集（Edit）」ボタン、「承認（Approve）/否認（Reject）」ボタン、「Diff View」トグル。
    - **Edit画面**: `VIEWER` 権限でのアクセス時にダッシュボードへリダイレクト、またはRead-onlyモード化。

### 1.2 エディタ機能の強化 (Priority: Medium)

- **クロスシート/クロスフロー コピー＆ペースト**:
  - **現状**: クリップボードデータが React state (`clipboard`) にあるため、シート切り替えやブラウザリロードで消失する。また、別タブ（別フロー）へのペーストができない。
  - **タスク**: クリップボード管理を `localStorage` または `navigator.clipboard` (API) への保存に変更し、**「別シートや別フローへのペースト」**を可能にする。
- **JSONインポート機能**:
  - **現状**: 「Export as JSON」はあるが、取り込む機能がない。
  - **タスク**: `edit.tsx` のメニューに「Import JSON」を追加し、ファイルアップロードまたはテキスト貼り付けでグラフデータを復元する機能を実装する。
- **スイムレーンの自動拡張**:
  - **現状**: 保存時や自動整列時にはサイズ計算されるが、ドラッグ操作中のリアルタイムな拡張がない。
  - **タスク**: ノードをレーンの端にドラッグした際、レーンの `width/height` を動的に拡張するインタラクションを追加する。

## 2. バックエンド (Server / GAS)

### 2.1 排他制御のUX向上 (Priority: Low)

- **現状**: `saveDraft` などの書き込み実行時に初めて `LockService` が機能する。編集開始時の競合検知がない。
- **タスク**:
  - 誰かが編集画面を開いた時点で、GASの `CacheService` (または `PropertiesService`) に「編集中フラグ（User ID + Timestamp）」を立てるAPIを作成。
  - フロントエンドで定期的に（またはページロード時に）このフラグをチェックし、他のユーザーが編集中であれば「〇〇さんが編集中です」とアラートを出す簡易ロック機構を実装する。

### 2.2 監査ログ (Priority: Medium)

- **現状**: 承認・否認などの操作ログが残っていない（バージョン履歴のコメントのみ）。
- **タスク**:
  - `System_Logs` シートを定義し、承認・却下・権限変更などの重要イベントを記録するロガー関数を実装する。

## 3. テスト (Testing)

### 3.1 権限・セキュリティの結合テスト

- **タスク**:
  - `VIEWER` 権限のユーザーがAPI経由で `saveDraft` や `approveFlow` を叩いた際、正しくエラー（例外）が返り、データが保護されることを確認するテストシナリオを実施する。
